### 1.2 专有变量

```css
--font-num: "SF Mono","JetBrains Mono",Menlo,monospace;  /* 所有数字、日期、标签、小标题 */
--subject-math:#5B8CFF; --subject-cs:#2DD4BF; --subject-eng:#F5B53F; --subject-pol:#F0626B;
--heat-0:#1B1E22; --heat-1:#3B2418; --heat-2:#7A3A1C; --heat-3:#C4521F; --heat-4:#FF6A2B; /* 浅色版：#EEF0F3 #FFD9C7 #FFB08A #FF8547 #F05A1A */
```

- 热力分档（分钟）：`0` / `<120` / `<240` / `<360` / `≥360`。
- 圆角：卡片 12px，按钮/输入 8px，chip 999px，tag 5px，日历格 10px。
- 阴影：深色不用阴影，靠 1px 描边分层；浅色卡片 `0 1px 2px rgba(0,0,0,.04)`。
- 间距：页面内边距 22px 28px；卡片内边距 18px 20px；卡片间距 16px。

## 3. 组件规则

| 组件 | 规则 |
|---|---|
| **侧栏 Rail**（桌面） | 宽 64px，仅图标（lucide 19px/1.7）；顺序：今日 / 计划 / 日历 / 统计 / 时光，底部搜索、设置；激活态 = `--card-2` 底 + 左侧 2px 橙色内阴影；顶部 32px 橙色方块 logo「考」 |
| **顶栏** | 左：`JOURNAL / <页名> · 2026.11.15 SUN`（等宽 12px，字距 .08em）；右：⌘K 搜索框 300px |
| **页标题** | 30px/600 + 右侧等宽灰色副标题；右侧放月份切换 `‹ 2026.11 ›` + 主按钮 |
| **卡片 Card** | `--card` 底 + 1px `--keyline`，12px 圆角；卡片标题 = 等宽 11px 大写、字距 .14em、`--ink-faint`，右侧放操作/计数（`--ink-soft`，强调操作用橙色） |
| **科目 Tag** | 等宽 11px/600，文字 = 科目色，底 = 科目色 12% 透明（`${color}1f`），最小宽 52px |
| **状态 Chip** | 999px 胶囊，1px 描边；选中：橙色描边 + 橙字 + `--brand-soft` 底 |
| **按钮** | 主：橙底黑字 600；次：描边 `--keyline` + `--ink-soft`；图标按钮 7px 9px |
| **分段 Seg** | 描边容器，选中段 `--card-2` 底 + `--ink` 字 |
| **复选框** | 16px/4px 圆角/1.5px `--ink-faint` 描边；选中：橙底 + 黑色对勾；完成文字删除线 + `--ink-faint` |
| **进度条** | 6px 高，槽 `--card-2`，填充 = 科目色或橙色；下方 11.5px 灰字「61% · 日均 26 题可达成」 |
| **圆环** | 9px 线宽，槽 `#1F2226`，圆头；中间等宽大数字 + 11px 灰色说明 |
| **大数字** | 倒计时 88px/600 等宽，字距 -.04em；统计值 24–30px 等宽 |

## 4. 逐页要点（对照截图）

- **today**：3 列首行 = 倒计时卡（40 格阶段刻度）｜今日环（时长/目标 + 连续天数）｜本周 7 柱（今天橙色）。第 2 行 1.25fr:1fr = 学习记录 + 状态 + 想法｜待办 + 本月目标。第 3 行 = 近 26 周热力条。
- **calendar**：标题行 + 4 个 KPI 卡（记录天数/时长/日均/达标天数）+ 7 列大日历卡；底部图例 + 说明文字。
- **plan**：完成度横幅（圆环 + 3 个统计）；目标 2 列卡片：数量型 = 大数字 + 进度 + 3 个小统计块 + 状态/打卡链接；清单型 = 子任务清单 + 「+ 子任务」；底部虚线横幅「结转到本月」。
- **goal**：面包屑；首行 5 格（圆环+数值 / 剩余 / 剩余天数 / 计划日均 / 按剩余追赶【橙色】）；下方 1.4fr:1fr = 打卡日历（格底色按数量加深蓝色）｜每周进度（达成绿色）+ 备注。
- **memory**：左侧 200px 月份索引；右侧竖线时间轴，节点圆环颜色 = 状态色，卡片含日期/状态/时长/科目/日记。
- **stats**：4 KPI；每日柱状图（达标深橙、今天亮橙、虚线 = 目标）；学科分布（堆叠条 + 行）｜状态分布（横条）。
- **annual**：4 KPI；全年热力（含月份刻度）；月度柱（当前月橙色、最高月深橙）｜年度学科分布。
- **search**：大输入框（聚焦态）+ 结果数；类型筛选 chips；结果行 = 日期 · 科目 tag + 命中类型 tag + 高亮文本 · 状态。
- **settings**：每节一张卡，左 240px 标题+说明，右侧控件；节顺序：考研目标 / 每日目标（滑杆 + 预设 chips）/ 科目预设 / 外观 / 自定义状态 / 数据管理。
- **login**：无外壳，居中 400px；顶部 logo + 「考研手帐」+ `D-398`；卡片内用户名/密码/橙色登录按钮。
- **learn-form / goal-form**：见组件规则；goal-form 有「拆分预览」灰色条（`previewCountSplit`）。
